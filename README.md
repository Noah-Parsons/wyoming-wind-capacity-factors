# P27 — Wyoming wind capacity factors

**Field:** Energy  
**Size:** Medium (one project season)  
**Time:** 2 months

## Question
How well do reanalysis-based wind-power estimates (ERA5) match reported generation from Wyoming wind farms, and where do they fail?

## Why it matters
Wyoming policy relies on modelled wind resource. Checking model against reported data is a verification question in your home field.

## Builds on
WEA work, EIA data experience

## Method
1. Get EIA-923 monthly generation per plant
2. Compute ERA5 hub-height wind and power-curve estimates
3. Analyse bias by season, terrain, plant age

## Deliverable
Report + DOI; share with the Wyoming Energy Authority study group.

## Risks
ERA5 download size, so request a small region.

## Before you start: novelty check
Search Google Scholar / arXiv / GitHub for: _ERA5 wind power capacity factor validation_. If the question is already answered, narrow it or pick another project.
